# 20. WALLET ARCHITECTURE HISTORY

A major architectural audit identified two wallet systems.

## System A
HMAC-derived wallets in UI code.

A wallet address/private key could be derived deterministically using:

- master seed;
- Firebase UID;
- chain.

## System B
Vault Engine.

The Vault Engine stores wallet records and encrypted private keys and maintains wallet states and transaction history.

The architectural conclusion was:

**Keep System B / Vault Engine.**

**Delete the HMAC wallet derivation from the UI/API wallet layer.**

The UI should obtain wallet information through:

**Identity Engine → Vault Engine**

This avoids duplicated wallet logic and centralizes sensitive operations.
